# Personal_Balance_Gui
Simple Python GUI to keep track of monthly expenses and savings linked to an excel file.

## Features
You'll be able to track expenses and check on your savings in two separate windows
![First screen shown as you open the program](https://github.com/Zerker-TF/Personal_Balance_Gui/blob/main/Gastos1.png)

On the Ahorros tab, you can follow along your savings and see the progress bar update in real time.
![screen after clicking Ver button](https://github.com/Zerker-TF/Personal_Balance_Gui/blob/main/ahorros.png)
